# 记管家 · 支持与帮助

## 常见问题

### 试用机制是怎样的？
免费下载即含 **30 天全功能试用**。试用期结束后不删任何数据，所有记录永久可看，仅不能再新增记录；¥25 一次买断后恢复完整功能，无订阅、无广告。

### 数据存在哪里？换手机会丢吗？
数据默认存在手机本地；登录 iCloud 后自动同步到您同一 Apple ID 的所有设备。换新机登录同一 Apple ID 即可自动同步。

### 附件（照片/视频）会同步到 iCloud 吗？
当前版本（1.0）附件仅存设备本地，不随 iCloud 同步。您可随时用「我的 → 数据 → 导出全部数据」把附件原文件带出。跨设备附件同步在后续版本规划中。

### 待办勾掉后去哪了？
已完成的待办会自动生成一条记录，出现在当天的时间轴和「今日记事」中；取消勾选会自动回收对应记录，不会堆积重复。

### 强提醒和普通提醒有什么区别？
强提醒（提醒列表中的橙色开关）使用「时效性通知」等级：可穿透专注模式，且未被处理时每 15 分钟重响一次，最多重响 3 次。

### 农历提醒是怎么重复的？
按农历日期每年重复，自动换算为当年的公历日期触发；若该年没有对应的闰月，则按普通月触发。

### 时间胶囊是什么？
写一句话封存（如半年后开启），密封期间任何页面都看不到内容；开启日当天会在「今日」页出现拆信卡。

### 如何清空所有数据？
我的 → 数据 → 清空全部数据（有二次确认）。数据会同时从本地和您 iCloud 的所有设备删除，操作前建议先导出备份。
